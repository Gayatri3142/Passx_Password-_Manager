# 🔐 PassX – Password Manager

PassX is a simple and user-friendly web-based password manager that helps you store and manage your website credentials in one place.

🌐 **Live Demo:** https://passx-tau.vercel.app/

## ✨ Features

- **Add Passwords:** Save website names, usernames, and passwords.
- **View Saved Passwords:** Display your saved credentials in a table.
- **Password Masking:** Passwords are displayed as asterisks for visual privacy.
- **Copy to Clipboard:** Easily copy website names, usernames, and passwords.
- **Delete Passwords:** Remove saved credentials whenever required.
- **Local Storage:** Save credentials in your browser using Local Storage.
- **Simple Interface:** Clean and easy-to-use design.

## 🛠️ Tech Stack

## 💾 Data Storage

- Password information is stored in the browser's Local Storage.
- Data remains available in the same browser and website origin.
- No external database or backend server is currently used.
- Clearing browser site data may permanently remove saved credentials.

## 🔒 Security Note

This project is developed for learning and demonstration purposes.

- Passwords are currently stored as plain text in browser Local Storage.
- Password masking only hides passwords visually; it does not encrypt them.
- Anyone with access to the browser profile or developer tools may be able to view stored credentials.
- Do not store real or sensitive passwords in the current version.
